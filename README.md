# bbeditSetup (archived)

**This repository is no longer maintained.** It was last updated in July 2022
and is kept read-only for reference.

My BBEdit configuration now lives in a private provisioning repository that
applies it with Ansible: preferences written with `defaults write
com.barebones.bbedit`, support files (scripts, text filters, clippings,
stationery, language modules), language servers and the Bare Bones Automator
actions. The few items still useful from this repository were moved there in
October 2026.

Much of the content here (colour schemes, clippings, language modules, filters)
came from other BBEdit users and was collected for learning, not written by me.
For current material, start with Bare Bones Software's own resources:

- [BBEdit support hub](https://www.barebones.com/support/bbedit/)
- [Expert preferences](https://www.barebones.com/support/bbedit/ExpertPreferences.html)
- [Clippings library](https://www.barebones.com/support/bbedit/clippings_library.html)
- [Language modules](https://www.barebones.com/support/bbedit/plugin_library.html)

BBEdit has been my favourite Mac text editor for years, and it still doesn't suck®.
